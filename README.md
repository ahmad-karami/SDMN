# Linux Networking and Containers

These projects were completed for the [COURSE NAME] course at [UNIVERSITY].

---

## [Docker_Status_API](Docker_Status_API/)
A small HTTP status API in Python on `/api/v1/status`, packaged as a Docker image.

## [Go_Container_Runtime](Go_Container_Runtime/)
A minimal container runtime in Go that uses namespaces, a cgroup memory limit, and `chroot` into an Ubuntu 20.04 base filesystem.

## [Network_Namespaces](Network_Namespaces/)
Four Linux network namespaces on two bridges, joined by a router namespace, with scripts to build the topology, ping between nodes, and remove it.
